# 스타일 가이드: 여기맞캠?

## 느낌 세 단어
- **귀엽다:** "여기 맞아?"라고 묻는 서비스 이름의 말투처럼 가볍게 다가갈 수 있게
- **친근하다:** 급한 순간에도 부담 없이 바로 열어 쓰게 (P1, P4 급할 때 가장 빠른 방법을 고름)
- **믿음직하다:** 길 안내 정보는 정확하고 최신이라고 믿을 수 있게 (P1 정확도, P6 최신 정보)

생김새는 귀엽고 친근하게(색, 둥근 모양), 길 안내 글자와 숫자는 또렷하게(믿음직함) 나눠 맡겨요.

## 색
주 색은 민트, 강조 색은 피치예요. 귀엽고 부드러운 느낌이라 골랐어요.

| 이름 | 색상 코드 | 쓰는 곳 |
|---|---|---|
| 민트 (main) | `#14a38b` | 아이콘, 선택된 칩 테두리, 지도 경로선, 강조 선 |
| 진한 민트 (main-strong) | `#0e7f6c` | 주 버튼 배경 (흰 글자와 대비 4.9:1), 링크 글자 |
| 연한 민트 (main-soft) | `#e6f7f3` | 선택된 칩 배경, 안내 카드 배경 |
| 피치 (accent) | `#ff9f6e` | 목적지 표시, 눈에 띄어야 하는 태그 배경 (글자는 진한 글자색) |
| 연한 피치 (accent-soft) | `#fff1e8` | 목적지 정보 카드 배경 |
| 진한 피치 (accent-ink) | `#9a4a1c` | 연한 피치 위 글자 (대비 5.6:1) |
| 내 위치 파랑 (me) | `#2f6fe4` | 내 위치 점 (지도 앱에서 익숙한 색) |
| 글자 (text) | `#1d2b28` | 본문, 제목 (흰 배경 대비 14.7:1) |
| 보조 글자 (sub) | `#5b6b67` | 설명, 거리, 기준일 (흰 배경 대비 5.6:1) |
| 선 (line) | `#e3ebe8` | 구분선, 카드 테두리 |
| 배경 (bg) | `#ffffff` | 화면 배경 |
| 주의 (warn) | 배경 `#fff6d9`, 글자 `#6b4b00` | 연결다리 없음 같은 주의 안내 |

- 피치 위에는 흰 글자를 쓰지 않아요 (대비 2.0:1로 읽기 어려움). 진한 글자색을 써요.
- 민트 `#14a38b` 위의 흰 글자도 대비가 3.2:1로 약해서, 글자가 올라가는 버튼은 진한 민트를 써요.
- 보조 글자보다 더 연한 회색은 쓰지 않아요.

## 글자
기본 글꼴만 써요: `system-ui, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`. 느낌은 **둥글고 친근하게**: 제목은 아주 굵고 크게, 버튼과 태그는 둥글게.

| 단계 | 크기 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| 제목 | 22px | 800 | 화면 제목, 목적지 이름 |
| 소제목 | 17px | 700 | 카드 제목, 지금 할 행동 |
| 본문 | 15px | 400~600 | 목록, 설명 |
| 보조 | 13px | 400 | 거리, 기준일, 안내 문구 |

거리, 층, 호수 같은 숫자는 굵게 써서 또렷하게 보여요.

## 모양
- **모서리 둥글기:** 카드와 시트 20px, 입력칸 16px, 버튼과 칩, 태그는 완전히 둥글게(알약 모양)
- **버튼:**
  - 주 버튼: 진한 민트 배경과 흰 글자, 높이 52px, 알약 모양
  - 보조 버튼: 흰 배경과 진한 민트 테두리
  - 누를 수 있는 것은 모두 높이 44px 이상이에요.

## 기본 부품
- **상단 바:** 서비스 이름 또는 ‹ 뒤로와 화면 제목, 오른쪽에 보조 정보
- **입력칸 (검색창):** 둥근 칸, 왼쪽에 돋보기
- **칩:** 검색 종류 고르기 (강의실, 건물, 편의시설)
- **카드 / 아래 시트:** 지도 위로 올라오는 정보 영역, 목록
- **버튼:** 주 버튼, 보조 버튼
- **안내 창:** 화면 위에 뜨는 짧은 질문 (위치 권한, "이 강의실이 맞나요?")
- **토스트:** 짧은 알림 문구
- 하단 메뉴는 쓰지 않아요 (와이어프레임에 없음)
