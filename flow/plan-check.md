# 플로우로 기획 다시 점검하기

## 1. 기능에서 플로우로

| 핵심 기능 | 어느 플로우, 몇 단계에 나오나 | 어느 화면에서 | 판정 |
|---|---|---|---|
| F1 내 위치·방향 + 목적지 방향 안내 | 플로우 1·2·3 1단계(내 위치), 플로우 1 2단계(지금 건물이 목적지인지, 옆 건물 안내, 거리), 플로우 1 3단계 갈림길(방향이 헷갈릴 때만 서 있는 방향 기준 화살표) | 내 위치 지도 (2.1), 목적지 확인 (1.1), 경로 안내 (2.0) | 약함: 내 위치와 목적지 건물 확인은 기본 길에 있지만, "바라보는 방향" 표시는 헷갈렸을 때 갈림길에서만 나옴 |
| F2 건물 내부 층별 지도 + 강의실 검색 | 플로우 1·2·3 1단계(호수 검색), 플로우 1 4단계·플로우 2 3단계·플로우 3 5단계(층별 지도), 검색 갈림길(지하 B101 확인, 검색 결과 선택) | 내 위치 지도 (2.1), 목적지 확인 (1.1), 검색 결과 선택 (1.2), 층별 지도 (2.2) | 들어감 |
| F3 건물 간 연결 통로·지름길 경로 | 플로우 2 2~3단계(붙어 있는 옆 건물이면 2.2에서 연결 통로까지 안내, 연결 층을 처음부터 표시), 플로우 1 4단계 갈림길(층이 연결되지 않으면 연결된 층 안내) | 층별 지도 (2.2) | 약함: 붙어 있는 건물의 연결 통로는 들어갔지만, 건물 사이 "실내 지름길"을 경로 안내(2.0)에 반영하는 길은 어느 플로우에도 없음 |
| F4 주변 랜드마크·로드뷰 기반 안내 | 플로우 3 2~3단계(목적지 확인에서 "주변 보기", 아는 건물·입구 사진·오르막 표시 확인 후 길찾기 시작) | 주변 랜드마크 / 로드뷰 (2.3) | 들어감 (단, 2.3 와이어프레임은 아직 없음) |
| 공통 정보 기준일 표시 | 플로우 1·2·3 기본 길(1.1, 2.0, 2.2에 기준일), 갈림길(정보 안내에서 확인·제보) | 목적지 확인 (1.1), 경로 안내 (2.0), 층별 지도 (2.2), 정보 안내 (3.0) | 들어감 |

## 2. 플로우에서 기획서로

플로우에는 있지만 기획서(기능, 니즈, 6.1 화면 목록과 화면 흐름)와 맞지 않는 것.

| 플로우에 있는 것 | 기획서와의 관계 |
|---|---|
| 앱 첫 화면이 내 위치 지도 (2.1), 홈/검색 (1.0)은 2.1에 합침 | 기획서 6.1 화면 흐름은 "홈에서 목적지 검색"으로 시작함. 1.0의 "최근 검색", "대학 선택"은 어느 플로우에도 나오지 않음 |
| 목적지 확인 (1.1), 검색 결과 선택 (1.2), 도착 완료 | F1, F2와 연결되지만 기획서 6.1 화면 목록에 없음. 도착 완료는 화면 흐름의 "도착 확인"에만 있음 |
| 주변 랜드마크 / 로드뷰 (2.3)를 목적지 확인에서 "주변 보기"로 들어감 | 기획서는 경로 안내 안에서 "내 위치 지도 + 층별 지도 + 랜드마크 보기가 탭으로 전환"이라고 함 |
| 건물 입구에서 층별 지도로, 강의실 앞에서 도착 완료로 자동 전환 | 기획서에 없음. 설계 원칙 "건물 안과 밖을 끊지 않는다"와는 맞음 |
| 위치 권한을 안 켜면 지도에 "여기서 출발" 핀을 찍음 | 기획서에 없음. 설계 원칙 "내 위치를 기준으로 안내"의 예외 상황 |

| 지금 내가 어디 있는지 모른다 | P1, P6 | 앱을 열면 내 위치 지도 (2.1)가 먼저 보임 | 해결 |
| 붙어 있는 건물을 하나로 착각한다 | P4, P6 | 목적지 확인 (1.1)에서 "옆 건물이에요", 경로 안내 (2.0)에서 잘못 들어간 건물 알림 | 해결 |
| 처음 물어본 사람도 몰라 여러 번 물었다 | P1 | 검색부터 도착까지 앱 안에서 이어짐 | 해결 |

## 4. 팀 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| F1 바라보는 방향 표시가 약함 | A. 2.1과 2.0 지도에 서 있는 방향 화살표를 늘 보여준다 | P6 니즈에 딱 맞아서 |
| F3 실내 지름길이 약함 | A. 경로 안내(2.0)가 실내 지름길을 경로에 넣어 안내한다 | P5 지름길 불편을 풀어서 |
| 기획서 6.1 화면 목록과 흐름이 플로우와 다름 | A. 기획서 6.1을 플로우에 맞게 고친다 (고친 문장은 팀 동의 후 반영, 기획서 변경 기록에 남김) | 기획서와 플로우가 한 가지 이야기를 해서 |
| 1.0을 2.1에 합치며 최근 검색, 대학 선택이 빠짐 | A. 둘 다 내 위치 지도(2.1)에 넣는다 | 기획서 원래 구성을 살릴 수 있어서 |
