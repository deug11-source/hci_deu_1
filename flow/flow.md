# 서비스 플로우

## 플로우 1: 처음 가는 강의실 찾기 (김서윤) [핵심]
퍼소나: 01 정확한 위치정보 확인형 김서윤 / 목표: 처음 가는 강의실까지, 사람에게 묻지 않고 지금 위치에서 이동을 시작한다
| 단계 | 화면 (ID) | 사용자 행동 | 다음 화면 | 갈림길 |
|---|---|---|---|---|
| 1 | 내 위치 지도 (2.1) | 앱을 열자마자 내 위치를 보고, 지도 위 검색창을 눌러 강의실 호수를 입력한다 | 목적지 확인 (1.1) | 결과 없음: 2.1에서 다시 검색해 달라고 안내 / 결과 여러 개: 검색 결과 선택 (새 화면) / 지하 표기 헷갈림(B101을 101로): "이 강의실이 맞나요?" 확인 질문 (새 화면) / 위치를 못 잡음: 위치 권한 켜기 안내 (새 화면) |
| 2 | 목적지 확인 (1.1) | 목적지 건물, 층, 거리, 걸리는 시간과 함께 지금 있는 건물이 목적지인지 확인하고 "길찾기 시작"을 누른다 | 경로 안내 (2.0) | 지금 있는 건물이 목적지: 건물 상세 / 층별 지도 (2.2)로 바로 감 / (그 밖의 갈림길은 정하는 중) |
