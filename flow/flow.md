## 플로우 1: 처음 가는 강의실 찾기 (김서윤) [핵심]
퍼소나: 01 정확한 위치정보 확인형 김서윤 / 목표: 처음 가는 강의실까지, 사람에게 묻지 않고 지금 위치에서 이동을 시작한다

|---|---|---|---|---|
| 1 | 내 위치 지도 (2.1) | 앱을 열자마자 내 위치를 보고, 지도 위 검색창을 눌러 강의실 호수를 입력한다 | 목적지 확인 (1.1) | 결과 없음: 2.1에서 다시 검색해 달라고 안내 / 결과 여러 개: 검색 결과 선택 (새 화면) / 지하 표기 헷갈림(B101을 101로): 목적지 확인 (1.1) 위에 "이 강의실이 맞나요?" 안내 창, "아니에요"를 누르면 B101과 101 두 후보를 검색 결과 선택 (새 화면)에서 보여줌 / 위치를 못 잡음: 위치 권한 켜기 안내 (새 화면), 권한을 안 켜면 출발 위치 직접 고르기 (새 화면)에서 지도로 출발 위치를 고른 뒤 2.1로 |
| 2 | 목적지 확인 (1.1) | 목적지 건물, 층, 거리, 걸리는 시간과 함께 지금 있는 건물이 목적지인지 확인하고(붙어 있는 옆 건물이면 "옆 건물이에요"라고 알려줌) "길찾기 시작"을 누른다 | 경로 안내 (2.0) | 지금 있는 건물이 목적지: 건물 상세 / 층별 지도 (2.2)로 바로 감 / 잘못 고른 목적지: 뒤로 가서 다시 검색 (내 위치 지도 2.1) / 취소: 홈으로 이동 (앱 첫 화면인 내 위치 지도 2.1) |
| 3 | 경로 안내 (2.0) | "지금 할 행동"을 보며 걷는다. 목적지 건물 입구에 도착하면 층별 지도로 자동으로 바뀐다 | 건물 상세 / 층별 지도 (2.2) | 자동 전환이 안 됨: 층별 지도 탭을 직접 누른다 / 경로를 벗어남: 2.0에서 경로를 다시 안내 / 방향이 헷갈림: 2.0에서 서 있는 방향 기준으로 화살표 표시 / 위치가 튐: 2.0에서 위치 다시 찾기 / 잘못 들어간 건물: 2.0에서 잘못 들어왔다고 알려주고 경로 다시 안내 |
| 4 | 건물 상세 / 층별 지도 (2.2) | 층과 강의실 위치를 확인하며 걷는다. 강의실 앞에 도착하면 도착 완료가 자동으로 뜬다 | 도착 완료 (새 화면) | 자동 전환이 안 됨: 도착 확인 버튼을 직접 누른다 / 층이 연결되지 않음: 2.2에서 연결된 층으로 가는 길 안내 / 정보가 틀림: 정보 안내 (3.0)에서 제보하고, 운영진이 확인해 보완 |
| 5 | 도착 완료 (새 화면) | 도착했음을 확인하고, 홈으로 가거나 정보가 맞았는지 확인하거나 틀린 점을 제보한다 | 홈 (내 위치 지도 2.1) | 정보 확인·제보: 정보 안내 (3.0) |
| 갈림길 | 정보 안내 (3.0) | 정보 기준일을 확인하거나 틀린 점을 제보한다 | 들어오기 전 화면 (2.2 또는 도착 완료) | 없음 |
