# 클로드 가상 사용성 평가

> 클로드가 퍼소나 역할로 한 가상 평가예요. 결과는 가설이고, 사람 UT로 확인해야 해요.

## 평가 1: 퍼소나 01 김서윤 (정확한 위치정보 확인형), 2026-11-27

퍼소나 근거: "지금 내가 어디에 있는지 알아야 다음에 어디로 가야 할지도 알 수 있어요." 핵심 키워드 정확성·위치 확인·정보 신뢰도·사전 판단. 불편: 안내 정보가 부정확하면 이동 방향에 대한 확신이 떨어진다.

## 화면 점검
지나간 화면: 2.1, 1.1, 2.0, 2.2, 2.4. 문제가 있는 것만 적었어요.

1. 지금 무슨 일이 일어나는지 보이나요?
   - 2.0 → 2.2 입구 도착 안내가 약 1초만 보임 (C4)
   - 2.2 기본 모습에는 강의실 앞에서 어떻게 되는지(자동으로 도착 완료가 뜨는지) 안내가 없음
2. 사용자가 쓰는 말인가요?
   - 지도 라벨 "EV" (C8)
3. 잘못 눌렀을 때 돌아갈 수 있나요?
   - 2.2 뒤로 버튼이 1.1에서 들어와도 2.0으로 감 (C10)
4. 같은 것은 같은 모양과 같은 이름인가요?
   - "EV"와 "엘리베이터" (C8)
   - 오른쪽 위 표시가 버튼 모양 (C11)
5. 실수하기 전에 막아 주거나, 실수했을 때 어떻게 하면 되는지 알려주나요?
   - 지도와 배너가 다른 길을 가리켜 잘못 갈 수 있음 (C2)
