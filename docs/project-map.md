## 핵심 기능 (기획서 그대로)
1. F1 내 위치·방향 + 목적지 방향 안내: 현재 위치와 바라보는 방향을 지도에 표시하고, 목적지가 어느 쪽에 있는지 화살표와 거리로 보여줍니다. 현재 있는 건물이 목적지 건물인지도 바로 알려줍니다.
2. F2 건물 내부 층별 지도 + 강의실 검색: 건물명·호수로 강의실을 검색하면 층과 복도 위치를 층별 지도에 보여줍니다. 지하(B101 등)와 지상을 구분해 표기하고, 건물 입구 기준 이동 방향을 안내합니다.
3. F3 건물 간 연결 통로·지름길 경로: 연결 다리, 붙어 있는 건물, 실내 지름길을 반영해 건물 사이 경로를 안내합니다. 층에 따라 연결 여부가 다른 경우(예: 4층만 연결 없음)도 반영합니다.
4. F4 주변 랜드마크·로드뷰 기반 안내: 목적지 주변의 알려진 건물과 입구 사진을 보여주고, "○○관에서 걸어서 약 N분"처럼 랜드마크 기준 위치를 알려줍니다. 실제 이동 거리와 방향을 함께 제공합니다.
5. 공통 정보 기준일 표시: 건물·경로 정보마다 마지막으로 확인한 날짜를 표시합니다.

## 주요 사용 시나리오 (기획서 그대로)
1. 시나리오 1 김서윤 (01): 처음 가는 강의실을 검색해 내 위치·방향과 목적지 쪽 화살표를 보고(F1), 지금 건물이 목적지가 아님을 알고 사람에게 묻지 않고 이동을 시작한다.
2. 시나리오 2 이도현 (02): 건물은 찾았지만 강의실 위치를 몰라 호수를 검색해 층별 지도에서 복도 위치를 확인하고(F2), 옆 건물로 넘어가야 하면 연결 통로 경로를 따라간다(F3).
3. 시나리오 3 박지민 (03): 목적지 주변의 아는 건물과 입구 사진을 먼저 확인하고, "○○관에서 걸어서 약 N분" 안내를 따라 이동한다(F4).

화면 흐름 (기획서 6.1): 홈에서 목적지 검색 → 경로 안내(내 위치 지도 + 층별 지도 + 랜드마크 보기가 탭으로 전환) → 도착 확인.
